## Why SVG Files?

GitHub strips inline CSS `style` attributes from rendered Markdown. This means techniques like:

```html
<!-- This does NOT work on GitHub -->
<hr style="background: linear-gradient(to right, transparent, #0F766E, transparent);" />
```

...are silently removed. The only reliable way to render custom visual elements on GitHub is to use SVG files served as images:

```html
<!-- This DOES work on GitHub -->
<img src="./assets/svg/divider.svg" alt="" width="100%" />
```

SVGs referenced as `<img>` tags are rendered faithfully by GitHub.

## Customizing Assets

### Changing the Accent Color

1. Open the SVG file in a text editor
2. Replace `#0F766E` with your desired color
3. Commit and push

### Creating New Assets

Follow these guidelines:
- Keep SVGs lightweight (minimal markup, no embedded fonts)
- Use the existing color palette for consistency
- Set explicit `width` and `height` on the root `<svg>` element
- Include a `viewBox` attribute for proper scaling
- Test by viewing the raw SVG in a browser before committing
