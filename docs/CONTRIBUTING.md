# Contributing

Thank you for your interest in contributing to this profile repository. While this is a personal profile README, suggestions and improvements are welcome.

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your changes (`git checkout -b improve/description`)
3. **Make your changes** following the guidelines below
4. **Test** by previewing the README on GitHub
5. **Submit a Pull Request** with a clear description

## Guidelines

### Design Consistency

- Follow the established color palette: `#0F766E`, `#111827`, `#334155`, `#F8FAFC`
- Do not use inline `style` attributes — GitHub strips them
- Use SVG images in `assets/svg/` for any decorative elements
- Keep the dark, minimal, professional aesthetic

### Code Quality

- Keep HTML minimal and semantic
- Use standard Markdown whenever possible over HTML
- Ensure all badge URLs are properly encoded
- Test that all external service URLs resolve correctly

### Commit Messages

Follow conventional commit format:

```
type: description

Examples:
feat: add new project card for XYZ
fix: correct broken badge URL
docs: update development guide
style: improve section spacing
chore: update workflow schedule
```

### What We Accept

- Bug fixes (broken links, rendering issues)
- Accessibility improvements
- Performance optimizations (smaller SVGs, fewer HTTP requests)
- Documentation improvements
- New GitHub-compatible visual elements

### What We Don't Accept

- Changes that break GitHub rendering compatibility
- Inline CSS styles (GitHub strips them)
- Dependencies on unstable or unmaintained services
- Dramatic design changes without discussion

## Questions?

Open an issue for discussion before submitting large changes.
